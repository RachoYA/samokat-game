# 🧭 Руководство по использованию компаса

## Где найти компас

Компас находится в **правом нижнем углу** игрового поля. Он представляет собой белый круг с четырьмя цветными стрелками, указывающими направления.

## Обозначения направлений

### 🔵 N (Север / North)
- **Цвет**: Синий
- **Ось**: Z- (вверх на экране)
- **Направление в 3D**: Уменьшение координаты Z

### 🟢 S (Юг / South)
- **Цвет**: Зеленый
- **Ось**: Z+ (вниз на экране)
- **Направление в 3D**: Увеличение координаты Z

### 🔴 E (Восток / East)
- **Цвет**: Красный
- **Ось**: X+ (вправо на экране)
- **Направление в 3D**: Увеличение координаты X

### 🟡 W (Запад / West)
- **Цвет**: Желтый
- **Ось**: X- (влево на экране)
- **Направление в 3D**: Уменьшение координаты X

## Текущая ориентация машины

Согласно `frontend/src/config/constants.js`:

```javascript
CAR_BASE_ROTATION_Y = 0
```

Это означает, что **передняя часть машины изначально смотрит на ВОСТОК (E)** — вправо на экране (красная стрелка).

## Углы поворота

```javascript
CAR_ROTATION_RIGHT = 0           // Восток (E) - исходное направление
CAR_ROTATION_LEFT = Math.PI      // Запад (W) - разворот на 180°
CAR_ROTATION_UP = -Math.PI / 2   // Север (N) - поворот на -90°
CAR_ROTATION_DOWN = Math.PI / 2  // Юг (S) - поворот на 90°
```

## Как настроить правильную ориентацию

1. **Запустите игру** и посмотрите на компас в правом нижнем углу
2. **Посмотрите, куда едет машина** при движении в разных направлениях
3. **Используйте компас как reference point**:
   - Если машина должна ехать на СЕВЕР (N/синий), она должна двигаться ВВЕРХ на экране
   - Если машина должна ехать на ВОСТОК (E/красный), она должна двигаться ВПРАВО на экране
   - И так далее

4. **Скажите мне**, в какую сторону (по компасу) смотрит передняя часть машины в исходном состоянии:
   - Например: "Передняя часть машины смотрит на СЕВЕР (N)"
   - Или: "Передняя часть машины смотрит на ВОСТОК (E)"
   - Или: "Передняя часть машины смотрит на ЮГ (S)"
   - Или: "Передняя часть машины смотрит на ЗАПАД (W)"

5. **Я скорректирую** `CAR_BASE_ROTATION_Y` и углы поворота соответственно

## Пример корректировки

### Если передняя часть смотрит на СЕВЕР (N):
```javascript
CAR_BASE_ROTATION_Y = -Math.PI / 2
CAR_ROTATION_UP = 0
CAR_ROTATION_DOWN = Math.PI
CAR_ROTATION_RIGHT = Math.PI / 2
CAR_ROTATION_LEFT = -Math.PI / 2
```

### Если передняя часть смотрит на ЮГ (S):
```javascript
CAR_BASE_ROTATION_Y = Math.PI / 2
CAR_ROTATION_DOWN = 0
CAR_ROTATION_UP = Math.PI
CAR_ROTATION_LEFT = Math.PI / 2
CAR_ROTATION_RIGHT = -Math.PI / 2
```

### Если передняя часть смотрит на ЗАПАД (W):
```javascript
CAR_BASE_ROTATION_Y = Math.PI
CAR_ROTATION_LEFT = 0
CAR_ROTATION_RIGHT = Math.PI
CAR_ROTATION_DOWN = Math.PI / 2
CAR_ROTATION_UP = -Math.PI / 2
```

## Система координат Babylon.js

- **Ось X**: Влево-Вправо (W ← → E)
- **Ось Y**: Вниз-Вверх (Ground ↕ Sky)
- **Ось Z**: Вперед-Назад (N ↑ ↓ S)

## Консоль

При запуске игры в консоли браузера появится сообщение:
```
🧭 Компас создан! N=Север(Z-/синий), S=Юг(Z+/зеленый), E=Восток(X+/красный), W=Запад(X-/желтый)
```

Это подтверждает, что компас создан и готов к использованию.
