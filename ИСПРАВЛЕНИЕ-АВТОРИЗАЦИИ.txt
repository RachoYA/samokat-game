ПРОБЛЕМА:
Frontend пытается обратиться к localhost:5001 из браузера
(CORS error: loopback address)

РЕШЕНИЕ:
API должен использовать относительный путь /api
Nginx проксирует /api на localhost:5001


=================================================================
ВАРИАНТ 1: Загрузить собранный frontend с вашего компьютера
=================================================================

# На вашем Mac (локально):

cd "/Users/grachyaalexanyan/Самокат игра"

# Загрузить собранный frontend на сервер
rsync -avz --progress --delete \
  frontend/build/ \
  racho@89.232.184.218:/var/www/samokat-game/frontend/build/

# Пароль: cv7AE5HpRC


=================================================================
ВАРИАНТ 2: Пересобрать на сервере с правильным .env
=================================================================

# На сервере (вы уже подключены):

cd /var/www/samokat-game/frontend

# Создайте правильный .env.production
cat > .env.production << 'EOF'
# Production Environment Variables
# Используем относительный путь - Nginx проксирует на localhost:5001
REACT_APP_API_URL=/api
EOF

# Пересоберите frontend
npm run build

# Перезагрузите Nginx
sudo systemctl reload nginx
