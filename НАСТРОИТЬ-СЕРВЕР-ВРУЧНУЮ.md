## Шаг 2: Скопируйте и выполните эти команды

После подключения к серверу скопируйте и выполните все команды ниже (по одной или все сразу):

```bash
# Установка Nginx (если нужно)
sudo apt update
sudo apt install -y nginx

# Установка PM2 (если нужно)
sudo npm install -g pm2

# Создание директорий для проекта
sudo mkdir -p /var/www/samokat-game
sudo chown -R racho:racho /var/www/samokat-game
mkdir -p /var/www/samokat-game/{backend,frontend,logs,deployment}

# Настройка Firewall
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw --force enable

# PM2 автозапуск
pm2 startup
```

После выполнения последней команды `pm2 startup`, скопируйте и выполните команду, которую она выведет (начинается с `sudo env PATH=...`).

---

## Шаг 3: Проверьте установку

```bash
node -v        # Должно показать v18.x.x
npm -v         # Должно показать версию npm
pm2 -v         # Должно показать версию PM2
nginx -v       # Должно показать версию Nginx
```
