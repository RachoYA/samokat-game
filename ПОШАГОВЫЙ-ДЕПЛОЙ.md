## ⚙️ Шаг 3: Настройка и запуск на сервере

### 3.1. Подключитесь к серверу

```bash
ssh racho@89.232.184.218
```

**Пароль:** `cv7AE5HpRC`

---

### 3.2. Установите зависимости Backend

```bash
cd /var/www/samokat-game/backend
npm install --production
```

---

### 3.3. Создайте .env файл

```bash
cat > .env << 'EOF'
PORT=5001
NODE_ENV=production
JWT_SECRET=$(openssl rand -hex 32)
JWT_EXPIRE=7d
DB_PATH=./database/microraion.db
EOF
```

---

### 3.4. Создайте директорию для базы данных

```bash
mkdir -p database
```

---

### 3.5. Запустите Backend через PM2

```bash
cd /var/www/samokat-game
pm2 start deployment/ecosystem.config.js
pm2 save
```

---

### 3.6. Настройте Nginx

```bash
sudo cp deployment/nginx.conf /etc/nginx/sites-available/samokat-game
sudo ln -s /etc/nginx/sites-available/samokat-game /etc/nginx/sites-enabled/samokat-game
sudo nginx -t
sudo systemctl reload nginx
```

---

### 3.7. Проверьте статус

```bash
pm2 status
pm2 logs --lines 20
```

---

### 3.8. Выйдите с сервера

```bash
exit
```
