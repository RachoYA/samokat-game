🚀 БЫСТРЫЙ СТАРТ — Микрорайон 3D
=================================

📋 ШАГ 1: Установка Node.js
---------------------------
Скачайте и установите Node.js 16+:
https://nodejs.org/

Проверьте установку:
node -v     (должно показать версию, например v18.12.0)
npm -v      (должно показать версию, например 8.19.2)


⚡ ШАГ 2: Установка зависимостей
--------------------------------
Откройте терминал в папке проекта и выполните:

npm run install:all

Это установит все необходимые пакеты для backend и frontend.
Процесс займет 2-5 минут.


🎮 ШАГ 3: Запуск игры
--------------------
В терминале выполните:

npm start

Это запустит:
✅ Backend API на http://localhost:5000
✅ Frontend на http://localhost:3000

Игра автоматически откроется в браузере!


🎯 ШАГ 4: Играем!
-----------------
1. Зарегистрируйтесь (введите имя пользователя)
2. Нажмите "Войти" или "Зарегистрироваться"
3. Играйте в 3D градостроительный пазл!


❌ ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:
---------------------------

Ошибка "Port 3000 is already in use":
  macOS/Linux: lsof -ti:3000 | xargs kill -9
  Windows: netstat -ano | findstr :3000 -> taskkill /PID <PID> /F

Ошибка "Cannot find module":
  rm -rf node_modules
  npm run install:all

3D не отображается:
  - Обновите браузер до последней версии
  - Проверьте что WebGL работает: https://get.webgl.org/
  - Обновите драйверы видеокарты
