ШАГ 1: НАСТРОЙТЕ DNS (в панели регистратора домена)
-----------------------------------------------------------------

Добавьте A-запись:
  Тип: A
  Имя: game
  Значение: 89.232.184.218
  TTL: 3600

Полная запись: game.grachia.ru → 89.232.184.218

⏱️ Подождите 15-30 минут для распространения DNS


ШАГ 2: ПРОВЕРЬТЕ DNS (на вашем компьютере)
-----------------------------------------------------------------

nslookup game.grachia.ru

Должно показать: Address: 89.232.184.218


ШАГ 3: НАСТРОЙТЕ СЕРВЕР
-----------------------------------------------------------------

ssh racho@89.232.184.218
# Пароль: cv7AE5HpRC

# Скопируйте и выполните все команды сразу:

cd /var/www/samokat-game && \
git pull && \
sudo npm install -g pm2 && \
pm2 start deployment/ecosystem.config.js && \
pm2 save && \
sudo cp deployment/nginx-domain.conf /etc/nginx/sites-available/samokat-game && \
sudo rm -f /etc/nginx/sites-enabled/default && \
sudo rm -f /etc/nginx/sites-enabled/samokat-game && \
sudo ln -s /etc/nginx/sites-available/samokat-game /etc/nginx/sites-enabled/samokat-game && \
sudo nginx -t && \
sudo systemctl reload nginx && \
pm2 status && \
echo "✅ Готово! Игра на http://game.grachia.ru"

=================================================================
🐛 TROUBLESHOOTING
=================================================================

Проблема: game.grachia.ru не открывается
Решение: Подождите распространения DNS (до 24 часов)
         Очистите кеш DNS: sudo dscacheutil -flushcache

Проблема: Показывает "Welcome to nginx!"
Решение: sudo rm /etc/nginx/sites-enabled/default
         sudo systemctl reload nginx

Проблема: 502 Bad Gateway
Решение: pm2 restart samokat-game-backend

Проблема: API не работает
Решение: pm2 logs
         Проверьте ошибки
