# 👤 Система пользователей в игре «Микрорайон»

## 📋 Описание

В игру добавлена полноценная система управления пользователями с сохранением прогресса в IndexedDB. Пользователи могут регистрироваться, входить в систему и отслеживать свою статистику.

---

## 🎨 Обновленный дизайн

### Светлая цветовая схема

Весь интерфейс переработан в более светлых тонах:

- **Фон**: Градиент от светло-голубого (#E3F5FF) через светло-зеленый (#F0FFF4) к мягкому зеленому (#D4F4DD)
- **Карточки**: Белый с градиентом к светло-зеленому (#FFFFFF → #F8FFFA)
- **Границы**: Полупрозрачные зеленые с мягкими тенями
- **Акценты**: Сохранены фирменные цвета Самокат (зеленый #00D563 и фиолетовый #7C5FF0)

## 🔐 Возможности авторизации

### 1. Вход существующего пользователя
- Введите имя пользователя
- Нажмите кнопку **"Войти"**
- Система загрузит вашу статистику

### 2. Регистрация нового пользователя
- Введите имя пользователя (обязательно)
- Нажмите **"Регистрация"** первый раз → откроется поле для email
- Введите email (опционально)
- Нажмите **"Создать аккаунт"**
- Готово! Вы зарегистрированы

### 3. Гостевой режим
- Нажмите **"Играть без сохранения"**
- Можно играть без регистрации
- Результаты не сохраняются в базу данных
- Локальный рекорд все равно сохраняется

## 🗄️ Техническая реализация

### IndexedDB структура

**База данных**: `MicrorayonGameDB` (версия 1)

**Хранилища (Object Stores)**:

1. **users**
   - Ключ: `id` (auto-increment)
   - Индексы: `username` (уникальный), `email`

2. **gameSessions**
   - Ключ: `id` (auto-increment)
   - Индексы: `userId`, `date`

3. **achievements**
   - Ключ: `id` (auto-increment)
   - Индексы: `userId`

### API класса UserDatabase

#### Основные методы

```javascript
// Регистрация
await userDB.registerUser(username, email);

// Вход
await userDB.loginUser(username);

// Выход
userDB.logoutUser();

// Получение пользователя по ID
await userDB.getUserById(userId);

// Обновление данных
await userDB.updateUser(userId, { bestScore: 500 });

// Сохранение игровой сессии
await userDB.saveGameSession(score, moves, missionsCompleted);

// Получение истории игр
await userDB.getUserGameHistory(userId, limit);

// Таблица лидеров
await userDB.getLeaderboard(limit);

// Достижения
await userDB.addAchievement(userId, name, description);
await userDB.getUserAchievements(userId);
```

### На стартовом экране

После входа пользователь видит:

- **Лучший результат**: максимальный набранный счет

### В конце игры

Экран финиша показывает:

- Количество выполненных миссий (X/3)

## 🔄 Автоматическое сохранение

### Что происходит автоматически:

1. **При первом запуске**:
   - Проверяется наличие сохраненного пользователя в localStorage
   - Если есть `currentUserId` → автоматический вход

2. **При регистрации/входе**:
   - ID пользователя сохраняется в localStorage
   - При следующем визите пользователь автоматически войдет

3. **При завершении игры**:
   - Результаты автоматически сохраняются в IndexedDB
   - Обновляется статистика пользователя:
     - `totalGames++`
     - `totalScore += score`
     - `bestScore = Math.max(bestScore, score)`

4. **При выходе**:
   - Очищается localStorage
   - Страница перезагружается

## 🔒 Приватность и безопасность

- **Локальное хранение**: Все данные хранятся только в браузере пользователя (IndexedDB + localStorage)
- **Нет серверов**: Нет отправки данных на внешние серверы
- **Анонимность**: Email опционален, можно играть только с именем
- **Гостевой режим**: Возможность играть вообще без регистрации

## 💡 Примеры использования

### Для разработчиков

```javascript
// Создание нового пользователя
const user = await userDB.registerUser('Игрок1', 'player@mail.ru');

// Вход
const user = await userDB.loginUser('Игрок1');

// Проверка текущего пользователя
if (userDB.currentUser) {
    console.log(`Текущий игрок: ${userDB.currentUser.username}`);
    console.log(`Лучший результат: ${userDB.currentUser.bestScore}`);
}

// Сохранение игры
await userDB.saveGameSession(450, 64, 3);

// Получение последних 5 игр
const history = await userDB.getUserGameHistory(userDB.currentUser.id, 5);
history.forEach(session => {
    console.log(`Игра от ${session.date}: ${session.score} очков`);
});

// Топ-10 игроков
const leaderboard = await userDB.getLeaderboard(10);
leaderboard.forEach((user, index) => {
    console.log(`${index + 1}. ${user.username}: ${user.bestScore}`);
});
```
