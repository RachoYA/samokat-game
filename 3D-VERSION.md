# 🎮 Микрорайон 3D - Светлая версия

## 🌟 Обзор

**Версия 3.0** — полностью переработанная 3D игра с потрясающей графикой в светлых тонах, системой пользователей и сохранением прогресса.

## ✨ Что нового в v3.0

### 🎨 Светлая цветовая схема

#### Фон и атмосфера
- **Небо**: Светло-голубой градиент `#E3F5FF`
- **Туман**: Легкая дымка для глубины сцены
- **Освещение**: Яркий дневной свет

#### Материалы
- **Земля**: Светло-зеленая трава (`RGB(0.7, 0.85, 0.7)`)
- **Дороги**: Светло-серый асфальт (`RGB(0.75, 0.75, 0.75)`)
- **Дальние здания**: Пастельные тона (`RGB(0.85, 0.87, 0.92)`)

#### Освещение
- **Солнце**: Направленный свет с мягкими тенями
- **Ambient**: Яркий дневной свет (интенсивность 0.9)
- **Подсветка Самокат**: Зеленая точечная подсветка

### 👤 Система пользователей

#### Авторизация
- Красивый стартовый экран с формой входа
- Регистрация новых пользователей
- Гостевой режим без сохранения

#### База данных (IndexedDB)

**Структура:**
```
MicrorayonGameDB
├── users (пользователи)
│   ├── id (auto-increment)
│   ├── username (уникальный)
│   ├── email

│   ├── id

│   ├── score
│   ├── moves

│   └── date
└── achievements (достижения - будущее)
```

- ✅ Все игровые сессии

## 🏗️ 3D Модели зданий

### 🏠 Дом
- Кубическая основа бежевого цвета
- Пирамидальная красная крыша
- 4 окна по сторонам со светом
- Высота: 3 единицы

### 🌳 Парк
- Зеленая травяная платформа
- 3 случайно расположенных дерева
- Стволы и кроны с реалистичными цветами
- Высота: 0.5 единиц

### ☕ Кафе
- Коричневая кубическая основа
- Красный навес над входом
- Светящаяся вывеска
- Высота: 2 единицы

### 🛒 Магазин
- Синяя кубическая основа
- Большая витрина с полупрозрачным стеклом
- Высота: 2.5 единицы

### 📦 Пункт доставки (Самокат)
- Зеленая основа (цвет бренда)
- Светящийся логотип Самокат
- Двойные зеленые двери
- Эффект свечения (glow layer)
- Высота: 2 единицы

### 🏭 Склад
- Серая основа
- Плоская крыша
- Большие ворота
- Высота: 3.5 единицы

### 🏢 Офис
- Фиолетовая кубическая основа
- Сетка окон (3×N)
- Светящиеся окна
- Самое высокое здание: 4 единицы

## 🎨 Визуальные эффекты

### Освещение и тени
- **Направленный свет** (солнце) с мягкими тенями
- **Ambient light** для общего освещения

### Particle Systems
- Частицы при размещении зданий
- Цвет частиц соответствует типу здания
- Гравитация и случайное направление

### Анимации
- Появление зданий (scale from 0 to 1)
- Пульсация текста с очками
- Hover эффекты на клетках сетки

## 💻 Техническая реализация

### Babylon.js API

#### Создание сцены
```javascript
this.scene = new BABYLON.Scene(this.engine);
this.scene.clearColor = new BABYLON.Color4(0.89, 0.96, 1, 1);
```

#### Камера
```javascript
this.camera = new BABYLON.ArcRotateCamera(
    'camera',
    -Math.PI / 4,    // Alpha (horizontal rotation)
    Math.PI / 3,     // Beta (vertical rotation)
    30,              // Radius (distance)
    targetPosition,  // Target
    this.scene
);
```

#### Материалы
```javascript
const mat = new BABYLON.StandardMaterial('mat', this.scene);
mat.diffuseColor = new BABYLON.Color3(r, g, b);
mat.specularColor = new BABYLON.Color3(r, g, b);
mat.emissiveColor = new BABYLON.Color3(r, g, b);
```

#### Тени
```javascript
const shadowGenerator = new BABYLON.ShadowGenerator(2048, sunLight);
shadowGenerator.useBlurExponentialShadowMap = true;
shadowGenerator.addShadowCaster(mesh);
mesh.receiveShadows = true;
```

### Интеграция с IndexedDB

#### Инициализация
```javascript
const request = indexedDB.open('MicrorayonGameDB', 1);

request.onupgradeneeded = (event) => {
    const db = event.target.result;
    db.createObjectStore('users', { keyPath: 'id', autoIncrement: true });
    db.createObjectStore('gameSessions', { keyPath: 'id', autoIncrement: true });
};
```

#### Сохранение игры
```javascript
async endGame() {
    const missionsCompleted = this.completedMissions.size;
    
    if (userDB.currentUser && !isGuestMode) {
        await userDB.saveGameSession(
            this.score, 
            this.moves, 
            missionsCompleted
        );
    }
}
```

## 📊 Производительность

### Оптимизации

1. **Тени**
   - Разрешение 2048×2048
   - Blur shadow map
   - Только для игровых объектов

2. **Post-processing**
   - FXAA вместо MSAA (быстрее)
   - Умеренный bloom

3. **Геометрия**
   - Простые примитивы (кубы, цилиндры)
   - Переиспользование материалов
   - LOD для дальних зданий (будущее)

4. **Частицы**
   - Лимит 200 частиц
   - Короткое время жизни (0.5с)
   - Автоматическая очистка

### Требования к системе

**Минимальные:**
- WebGL 1.0
- 2GB RAM
- Интегрированная графика

**Рекомендуемые:**
- WebGL 2.0
- 4GB+ RAM
- Дискретная видеокарта
- Современный браузер (Chrome/Edge/Firefox)
