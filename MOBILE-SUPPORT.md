# 📱 Мобильная адаптация

Игра "Самокат Микрорайон" полностью адаптирована для мобильных устройств!

## ✨ Возможности

### 📐 Адаптивный дизайн
- **Tablets (1024px)**: Оптимизированный интерфейс для планшетов
- **Mobile (768px)**: Компактный UI для смартфонов
- **Small mobile (480px)**: Максимально компактный дизайн
- **Landscape mode**: Специальная оптимизация для горизонтальной ориентации

### 🎮 Touch-управление
- **Вращение камеры**: Свайп одним пальцем
- **Масштабирование**: Pinch двумя пальцами
- **Панорамирование**: Касание двумя пальцами и перемещение
- **Выбор здания**: Тап по карточке
- **Размещение здания**: Тап по клетке на поле

### 🎨 Адаптивный UI

#### Панель статистики
- Компактные карточки на мобильных
- Автоматический перенос на маленьких экранах
- Скрытие меток в ландшафтном режиме

#### Панель миссий
- Сворачиваемая панель справа
- Полноэкранный режим на маленьких устройствах
- Вертикальная прокрутка

#### Карточки зданий
- Горизонтальный скролл на мобильных
- Увеличенные области нажатия (44px минимум)
- Touch-friendly анимации

### 🚀 Производительность

#### Оптимизации для мобильных:
- Адаптивное качество рендеринга
- Оптимизированная инерция камеры
- Плавные touch-жесты
- Отключение hover-эффектов на touch-устройствах

## 🎯 Управление

### На мобильных устройствах:

#### Камера:
- **1 палец** (свайп): Вращение камеры вокруг поля
- **2 пальца** (pinch): Масштабирование (zoom)
- **2 пальца** (свайп): Перемещение камеры (pan)

#### Игра:
- **Тап по карточке**: Выбрать здание
- **Тап по клетке**: Поставить здание
- **Тап по зданию**: Посмотреть информацию
- **Кнопка "⋮"**: Свернуть/развернуть панель миссий

### На десктопе:

#### Камера:
- **Левая кнопка мыши**: Вращение камеры
- **Правая кнопка мыши**: Перемещение камеры
- **Колесо мыши**: Масштабирование

#### Игра:
- **Клик по карточке**: Выбрать здание
- **Клик по клетке**: Поставить здание
- **Hover над зданием**: Подсветка

## 🔧 Технические детали

### HTML Meta Tags
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover" />
<meta name="mobile-web-app-capable" content="yes" />
<meta name="apple-mobile-web-app-capable" content="yes" />
```

### CSS Media Queries
- `@media (max-width: 1024px)` - Планшеты
- `@media (max-width: 768px)` - Мобильные
- `@media (max-width: 480px)` - Маленькие мобильные
- `@media (max-height: 500px) and (orientation: landscape)` - Ландшафт
- `@media (hover: none) and (pointer: coarse)` - Touch-устройства

### Babylon.js Touch Settings
```javascript
camera.panningSensibility = 50;
camera.angularSensibilityX = 2000;
camera.angularSensibilityY = 2000;
camera.pinchPrecision = 100;
camera.pinchDeltaPercentage = 0.01;
camera.inertia = 0.9;
camera.panningInertia = 0.9;
```

## 💡 Советы для мобильной игры

1. **Поворачивайте устройство**: В ландшафтном режиме больше места для игры
2. **Используйте pinch-zoom**: Приближайтесь для точного размещения зданий
3. **Сворачивайте панели**: Используйте кнопку "⋮" для большего обзора
4. **Включите "Не беспокоить"**: Уведомления могут прерывать игру
5. **Закройте фоновые приложения**: Для лучшей производительности

## 🎉 Установка как PWA

Игру можно установить как приложение на домашний экран!

### iOS:
1. Откройте игру в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой)
3. Выберите "На экран 'Домой'"
4. Нажмите "Добавить"

### Android:
1. Откройте игру в Chrome
2. Нажмите меню (три точки)
3. Выберите "Установить приложение" или "Добавить на главный экран"
4. Нажмите "Установить"

## 📞 Поддержка

Если у вас проблемы на мобильном устройстве:

1. Проверьте версию браузера (должна быть актуальной)
2. Очистите кэш браузера
3. Перезагрузите страницу
4. Попробуйте другой браузер
5. Проверьте доступ к WebGL: https://get.webgl.org/
