# 🚀 Быстрый Деплой на Сервер

## ⚡ Самый быстрый способ

### Шаг 1: Настройте сервер (только один раз)

```bash
# Подключитесь к серверу
ssh racho@89.232.184.218
# Введите пароль: cv7AE5HpRC

# Скопируйте и выполните эти команды:
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt update && sudo apt upgrade -y
sudo apt install -y nodejs nginx
sudo npm install -g pm2
sudo mkdir -p /var/www/samokat-game
sudo chown -R racho:racho /var/www/samokat-game
mkdir -p /var/www/samokat-game/{backend,frontend,logs,deployment}
sudo ufw allow 22/tcp && sudo ufw allow 80/tcp && sudo ufw allow 443/tcp
sudo ufw --force enable
pm2 startup

# Закройте соединение
exit
```

### Шаг 2: Запустите деплой

```bash
# Из корневой папки игры на вашем компьютере
./deployment/deploy.sh
```

**Готово!** Игра будет доступна на **http://89.232.184.218**

---

## 📝 Что делает скрипт деплоя?

1. ✅ Собирает React frontend (`npm run build`)
2. ✅ Загружает файлы на сервер через `rsync`
3. ✅ Устанавливает зависимости на сервере
4. ✅ Создает `.env` с настройками
5. ✅ Запускает backend через PM2
6. ✅ Настраивает Nginx для проксирования

## 🔄 Как обновить игру после изменений?

Просто запустите деплой снова:

```bash

```

Скрипт автоматически:
- Соберет новую версию
- Загрузит изменения
- Перезапустит приложение

## 🐛 Если что-то пошло не так


### Frontend не обновился:

### Сайт не открывается:
```bash

# Проверьте Nginx
sudo systemctl status nginx
sudo nginx -t
```

## 🎯 Полезные команды

### Управление приложением:
```bash
pm2 status              # Статус
pm2 logs               # Логи в реальном времени
pm2 restart all        # Перезапуск
pm2 stop all           # Остановка
pm2 monit              # Мониторинг ресурсов
```

### Nginx:
```bash
sudo systemctl status nginx    # Статус
sudo systemctl restart nginx   # Перезапуск
sudo nginx -t                  # Тест конфигурации
```

### Логи:
```bash
# Backend логи
pm2 logs samokat-game-backend

# Nginx логи
sudo tail -f /var/log/nginx/samokat-game-access.log
sudo tail -f /var/log/nginx/samokat-game-error.log
```
