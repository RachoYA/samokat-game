## 📋 Шаг 1: Настройка DNS

### Добавьте A-запись для поддомена

Зайдите в панель управления вашего регистратора домена (где зарегистрирован grachia.ru) и добавьте DNS-запись:

```
Type: A
Name: game
Value: 89.232.184.218
TTL: 3600 (или Auto)
```

**Полная запись:**
```
game.grachia.ru → 89.232.184.218
```

### Популярные регистраторы:

<details>
<summary>Reg.ru</summary>

1. Войдите на https://www.reg.ru/
2. Перейдите в "Мои домены"
3. Выберите grachia.ru
4. Нажмите "Управление зоной DNS"
5. Добавьте запись:
   - Тип: A
   - Субдомен: game
   - IPv4-адрес: 89.232.184.218
6. Сохраните
</details>

<details>
<summary>Cloudflare</summary>

1. Войдите на https://dash.cloudflare.com/
2. Выберите grachia.ru
3. Перейдите в DNS → Records
4. Add record:
   - Type: A
   - Name: game
   - IPv4 address: 89.232.184.218
   - Proxy status: DNS only (серое облачко)
5. Save
</details>

<details>
<summary>Другие регистраторы</summary>

Принцип одинаковый:
- Тип: A
- Имя/Субдомен: game
- Значение/IP: 89.232.184.218
</details>

⏱️ **Время распространения DNS:** 5 минут - 24 часа (обычно 15-30 минут)

## 🖥️ Шаг 2: Настройка на сервере

Подключитесь к серверу:

```bash
ssh racho@89.232.184.218
```

### 2.1. Установите PM2 (если еще не установлен)

```bash
sudo npm install -g pm2
```

### 2.2. Запустите Backend

```bash
cd /var/www/samokat-game

# Запуск через PM2
pm2 start deployment/ecosystem.config.js

# Сохранить конфигурацию
pm2 save

# Автозапуск
pm2 startup
# Выполните команду, которую выведет pm2 startup
```

### 2.3. Настройте Nginx для домена

```bash
# Скопируйте конфигурацию с доменом
sudo cp /var/www/samokat-game/deployment/nginx-domain.conf /etc/nginx/sites-available/samokat-game

# Удалите старый симлинк (если есть)
sudo rm -f /etc/nginx/sites-enabled/samokat-game

# Создайте новый симлинк
sudo ln -s /etc/nginx/sites-available/samokat-game /etc/nginx/sites-enabled/samokat-game

# Проверьте конфигурацию
sudo nginx -t

# Перезагрузите Nginx
sudo systemctl reload nginx
```

### 2.4. Проверьте статус

```bash
# PM2
pm2 status
pm2 logs

# Nginx
sudo systemctl status nginx
```

## 🔒 Шаг 3: Настройка HTTPS (SSL) - РЕКОМЕНДУЕТСЯ

После того, как DNS настроен и игра работает на HTTP:

### 3.1. Установите Certbot

```bash
sudo apt update
sudo apt install -y certbot python3-certbot-nginx
```

### 3.2. Получите SSL сертификат

```bash
sudo certbot --nginx -d game.grachia.ru

# Следуйте инструкциям:
# 1. Введите email
# 2. Согласитесь с условиями (Y)
# 3. Выберите опцию 2 (Redirect HTTP to HTTPS)
```

### 3.3. Автоматическое обновление

```bash
# Тест автообновления
sudo certbot renew --dry-run

# Certbot автоматически настроит cron для обновления
```

## 🐛 Troubleshooting

### Проблема: game.grachia.ru не открывается

**Решение:**
1. Проверьте DNS (может потребоваться время)
2. Очистите кеш DNS на компьютере:
   ```bash
   # Mac:
   sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
   
   # Windows:
   ipconfig /flushdns
   ```
3. Попробуйте в режиме инкогнито

### Проблема: Показывает "Welcome to nginx!"

**Решение:**
```bash
ssh racho@89.232.184.218
sudo rm /etc/nginx/sites-enabled/default
sudo systemctl reload nginx
```

### Проблема: API не работает

**Решение:**
```bash
ssh racho@89.232.184.218
pm2 logs
# Проверьте ошибки и перезапустите:
pm2 restart samokat-game-backend
```

### Проблема: 502 Bad Gateway

**Решение:**
```bash
# Проверьте, что backend запущен:
ssh racho@89.232.184.218
pm2 status
# Если не запущен:
cd /var/www/samokat-game
pm2 start deployment/ecosystem.config.js
```
