# 3D Models Directory

Поместите сюда ваши .glb модели:

- `house.glb` - модель дома
- `park.glb` - модель парка
- `cafe.glb` - модель кафе
- `shop.glb` - модель магазина
- `delivery.glb` - модель центра доставки
- `warehouse.glb` - модель склада
- `office.glb` - модель офиса
- `car.glb` - модель машины
- `person.glb` - модель человека

## Требования к моделям:

1. **Формат**: GLB (бинарный GLTF)
2. **Размер**: < 2MB на модель
3. **Pivot Point**: В нижнем центре модели (0, 0, 0)
4. **Масштаб**: ~2 метра для зданий, ~0.5 метра для машин/людей
5. **Полигоны**: < 5000 для оптимальной производительности

Если модели отсутствуют, игра автоматически использует процедурную генерацию.
