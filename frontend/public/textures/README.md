# Textures Directory

Поместите сюда ваши текстуры:

- `ground.jpg` - текстура земли/травы
- `road.jpg` - текстура дороги/асфальта

## Требования к текстурам:

1. **Формат**: JPG или PNG
2. **Размер**: 512x512 или 1024x1024
3. **Tileable**: Текстуры должны плавно повторяться

Если текстуры отсутствуют, игра использует цветовую заливку по умолчанию.
